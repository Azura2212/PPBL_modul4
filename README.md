# Pendaftaran Kegiatan Kampus

Aplikasi praktikum Flutter untuk pendaftaran Seminar Teknologi Mobile. Fitur:

- Formulir nama, email, persetujuan syarat, dan pilihan sesi.
- Penyimpanan pendaftar menggunakan Provider.
- Chat sederhana lokal antara peserta dan petugas.
- Statistik pendaftar per sesi dengan chart batang.
- Navigasi adaptif dengan NavigationBar atau NavigationRail.
- Detail kegiatan dan informasi lokasi.

Tab Peta menampilkan koordinat dan informasi lokasi sebagai pengganti Google Maps,
sehingga aplikasi dapat dijalankan tanpa API key Google Maps.

## Menjalankan aplikasi

```shell
flutter pub get
flutter run
```

## Menjalankan pengujian

```shell
flutter test
```
